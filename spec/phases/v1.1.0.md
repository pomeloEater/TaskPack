## 목표

**처음 쓰는 사람이 설치부터 첫 사용까지 막히지 않게 한다.**

인터뷰에서 꼽은 막히는 곳은 두 가지다.
1. 설치 전: .NET 8 데스크톱 런타임을 따로 받아야 한다 (ARM PC에서는 설치가 막힐 수도 있다)

## 결정 사항

### 3·4. 설치 파일 두 종류

| | .NET 포함판 (기본) | lite |
|---|---|---|
| 파일 이름 | `TaskPack-Setup-1.1.0.exe` | `TaskPack-Setup-1.1.0-lite.exe` |
| 빌드 | self-contained win-x64, ReadyToRun | framework-dependent (지금 방식) |
| 크기 | 약 51MB (1.1.0 빌드 실측 51.3MB) | 약 5MB (실측 4.6MB) |
| .NET 확인 | 하지 않음 | 함. ARM64 Windows는 `Program Files\dotnet\x64\shared\...`도 확인 |
| ARM PC | x64 에뮬레이션으로 실행 (런타임 불필요) | x64 런타임 필요 |

- 두 판은 같은 AppId를 쓴다. 어느 쪽을 설치해도 같은 프로그램의 업그레이드로 취급한다.
- **위험**: 포함판 위에 lite을 덮어 설치하면 포함판의 런타임 파일이 설치 폴더에 남는다. 남은 파일 때문에 실행 방식이 섞일 수 있으므로, 설치 전에 이전 설치 파일을 정리한다(Inno `[InstallDelete]`로 `{app}` 안의 프로그램 파일 삭제. 사용자 데이터는 `%APPDATA%`에 있어서 영향 없음).
- 프로그램은 자기가 어느 판인지 안다 (빌드 때 넣는 값). 새 버전 알림이 같은 판의 파일을 알려 주는 데 쓴다.
- 홈페이지: 큰 버튼은 포함판, 그 아래 작은 글씨로 "이미 .NET 8이 있다면 lite(약 4.5MB)". 최신 릴리스 파일 이름 규칙(`-lite`)으로 두 링크를 자동으로 찾는다.

### 5. 빈 가방 안내 + 고정 알림

- 아이템이 하나도 없는 가방은 가운데에 버튼 두 개를 보여 준다: **[작업표시줄 앱 가져오기] [파일로 넣기]**. 지금의 안내 문구 규칙(새 가방·첫 실행에만 문구)을 이 버튼으로 대신한다.
- 작업표시줄에 고정되어 있지 않으면 가방 아래에 알림 띠를 보여 준다: "작업표시줄에 고정하면 한 번에 열려요 **[고정하기]** **[×]**".
  - [고정하기]: 지금의 "작업표시줄에 고정하기…"와 같은 동작(시작 메뉴 바로가기를 탐색기에서 보여 주고 안내)
  - [×]: 다시 보지 않기 (config에 저장)
- 첫 실행 때 설정 창이 자동으로 열리는 동작은 없앤다.

### 6. 새 버전 알림 (기본안)

- 가방을 열 때, 마지막 확인으로부터 24시간이 지났으면 GitHub 최신 릴리스를 뒤에서 조회한다. 실패하면 조용히 넘어간다(오프라인 등).
- 새 버전이 있으면 가방 아래에 띠: "새 버전 1.1.1이 나왔어요 **[받기]** **[×]**". 고정 알림과 함께 뜨면 새 버전 띠를 위에 둔다.
  - [받기]: 지금 쓰는 판과 같은 판의 설치 파일을 브라우저로 내려받는다. 못 찾으면 릴리스 페이지를 연다.
  - [×]: 그 버전은 다시 알리지 않는다 (다음 버전이 나오면 다시 알림)
- 설정 → 기본 설정에 "버전" 카드: 현재 버전, 최신 버전, [지금 확인], "새 버전 자동 확인" 스위치(기본 켜짐).
- 보내는 정보는 없다. GitHub 공개 API에서 최신 릴리스 정보만 읽는다. README·홈페이지 질문에 이 내용을 적는다.

### 7. 탭 아이콘 이모티콘

- 탭 아이콘을 고르는 화면은 **이모티콘 목록이 먼저**, 그 아래 "그림 파일에서 고르기"(지금 기능)를 둔다.
- 컬러 이모티콘: Microsoft **Fluent 이모지**(MIT 라이선스)에서 가방 탭에 어울리는 **약 60개**를 골라 48px PNG로 넣는다. 증가 용량 목표 약 100KB.
  - 라이선스 전문을 `assets/emoji/LICENSE`와 설치 폴더 `licenses\`에 넣는다.
  - 받을 때 사용자 확인을 받는다 (GitHub microsoft/fluentui-emoji).
- 목록에 없는 이모티콘은 직접 입력할 수 있다. WPF가 컬러 글꼴을 그리지 못해 **단색**(탭 글자색)으로 보인다.
- 저장: `bag.json`에 `tabEmoji`(문자열). `tabIcon`(그림 파일)과 둘 중 하나만 쓴다. 백업에 그대로 포함된다.
- "이름 숨기기"는 이모티콘에도 적용된다.

## 확인이 더 필요한 것

- 새로 만든 가방에 기본 이모티콘(예: 🎒)을 자동으로 넣을지. 기본안은 **넣지 않음**(지금처럼 이름만, 고르기 화면에서 이모티콘이 먼저 보임).
- 고정 알림 띠와 새 버전 띠의 문구·모양은 S2·S3에서 화면을 보며 다듬는다.
