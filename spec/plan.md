# TaskPack 설계 (v2)

작업표시줄에 고정하는 가방 아이콘. 누르면 마비노기 가방 같은 격자형 창이 작업표시줄 옆에 펼쳐지고, 칸을 한 번 누르면 프로그램이 실행된다. 가방은 한 창 안의 탭으로 여러 개 둘 수 있다.

- 영어 이름: TaskPack (실행 파일 `TaskPack.exe`)
- 위치: `D:\Development2026\private\taskpack`
- 기술: C# / .NET 10 / WPF (1.1.1부터. 1.1.0까지는 .NET 8), 외부 패키지 없음

## 목표 (사용자 요구)

1. 작업표시줄의 작업표시줄 아이콘을 누르면 가방이 열리고, 칸을 한 번 누르면 프로그램이 실행된다.
2. 작업표시줄 아이콘을 자유롭게 바꿀 수 있다.
3. 작업표시줄이 가로면 위(또는 아래)에, 세로면 옆에 펼쳐진다.
4. 마비노기 가방처럼 고정된 칸에 아이템을 자유 배치한다.
5. (v2) 가방 여러 개를 탭으로 관리한다. 탭 이름 변경·삭제, 탭 아이콘, 이름 숨기기.
6. (v2) 가방별 크기 설정, 백업 내보내기·불러오기.
7. (v2) 작업표시줄에 고정된 앱과 시작 메뉴 앱을 가방에 넣는다.
8. (v2) TaskPack.exe 자체 아이콘 (서류가방 + 남자 구두, B2 청록+갈색).

## v1 → v2 결정 사항

| 항목 | v1 | v2 |
|---|---|---|
| 가방 여러 개 | 가방마다 바로가기를 따로 고정 | **한 가방 창 안의 탭**. 작업표시줄 고정은 하나 |
| 실행 인자 | `--bag <id>` | 없음. 마지막에 보던 탭으로 열림 |
| 새 가방 기본 크기 | 5×4 | **3×3** (기존 가방은 저장된 크기 유지) |
| 설정 | bag.json 직접 수정 | ⚙ 설정 창 |
| 작업표시줄 앱 끌어 넣기 | - | Windows가 작업표시줄 밖으로 끌기를 막아 불가능 → "고정 앱 가져오기" + "Windows 앱 목록"에서 끌기 (사용자 선택: 둘 다) |
| 설정의 "이름 숨기기/아이콘" | - | 탭 꾸미기로 확정 (탭 아이콘 추가·변경·삭제, 탭 이름 숨기기) |
| 테마 (v2.1) | 다크 고정 | 전체: 시스템/라이트/다크. 가방별: 전체 설정/시스템/라이트/다크/커스텀(색 지정) |
| 끌기 (v2.1) | 칸끼리만 | + 탭 순서 바꾸기, 아이템을 다른 탭에 놓아 그 가방으로 옮기기, 제목 줄 빈 곳으로 창 옮기기 |

## 화면

```
[📌] [🎮 게임] [아버지가방] [개발도구] [+ 새 가방] ········ [⚙]
┌───┬───┬───┐
│   │   │   │   ← 선택한 탭의 가방 칸
└───┴───┴───┘
```

### 열기·닫기
- 가방은 마우스가 있는 모니터에서 작업표시줄 쪽 가장자리에 붙어 뜬다.
  - 판정: 모니터 전체 영역(rcMonitor)과 작업 영역(rcWork)의 차이가 있는 쪽이 작업표시줄.
  - 아래 → 위로, 위 → 아래로, 왼쪽/오른쪽 → 옆으로. 자동 숨김이면 마우스 위쪽.
  - 탭을 바꿔 창 크기가 달라지면 처음 연 마우스 위치 기준으로 다시 배치한다.
- 닫히는 경우: 칸 실행 직후 / 바깥 클릭(포커스 잃음) / Esc / 작업표시줄 아이콘 다시 클릭.
- 재클릭 토글: 열린 창은 이름 있는 이벤트 `Local\TaskPack.Drawer`를 갖는다. 새 프로세스는 이를 발견하면 신호만 보내고 종료한다. 포커스를 잃어 숨은 뒤에도 약 400ms 동안 이벤트를 유지한다.
- 📌: 켜면 포커스를 잃어도 닫히지 않는다 (파일을 끌어 넣을 때).
- 애니메이션: 열 때 작업표시줄 쪽에서 12 DIP 미끄러져 나오며 나타남(0.16초), 닫을 때 반대로 사라짐(0.12초). Windows "애니메이션 효과"가 꺼져 있으면 생략.
- 안내 문구: "+ 새 가방"으로 방금 만든 빈 가방, 또는 가방이 하나뿐이고 비어 있을 때(처음 설치)만 보인다.
- 작업표시줄 표시: 가방 창은 작업표시줄에 나타난다. 프로세스 앱 식별자를 작업표시줄 바로가기와 같은 `TaskPack.Drawer`로 정해, 고정한 작업표시줄 아이콘 아래에 "실행 중"으로 묶인다. 최소화되면(작업표시줄 아이콘 클릭, Win+D) 닫는다.

### 탭
- 한 번 클릭: 그 가방으로 바꾼다.
- 더블클릭: 이름 입력칸과 ✕(삭제)가 나타난다. Enter 또는 다른 탭 클릭 → 이름 저장 후 원래대로. 입력칸에서 Esc → 취소.
- 빈 이름은 저장하지 않는다.
- ✕: 아이템이 있는 가방이면 확인을 받는다. 마지막 남은 가방은 지울 수 없다(✕ 숨김).
  - 지운 가방은 바로 없애지 않고 `deleted\<id>-<시각>`로 옮긴다.
- + 새 가방: "새 가방"(3×3) 탭을 추가하고 바로 이름 입력 상태로 만든다.
- 탭 아이콘이 있고 "이름 숨기기"가 켜져 있으면 아이콘만 보이고, 이름은 툴팁으로 보인다.
- 탭 끌기: 다른 탭 위에 놓으면 그 자리로 옮긴다(오른쪽으로 끌면 뒤, 왼쪽이면 앞).
- 칸 아이템을 다른 탭 위에 놓으면 그 가방의 첫 빈칸으로 옮긴다. 가방 폴더 안 파일(가져온 바로가기)은 파일도 함께 옮긴다. 빈칸이 없으면 알린다.
- 제목 줄 빈 곳(탭·버튼 제외)을 끌면 창이 옮겨진다. 그 뒤로는 탭을 바꿔 크기가 달라져도 자리를 지키고 화면 안으로만 밀어 넣는다. 다음에 열면 다시 작업표시줄 옆.

### 테마
- 전체 테마(config.theme): 시스템(레지스트리 AppsUseLightTheme) / 라이트 / 다크.
- 가방별 테마(bag.theme): null=전체 설정, 또는 시스템/라이트/다크/커스텀. 탭을 바꾸면 창 색도 바뀐다.
- 커스텀: 가방 창 배경 = 지정 색. 밝기(0.55 기준)로 글자·칸 겹침을 흰색 또는 검은색으로 정한다. 색은 추천 12색 또는 Windows 색 고르기 창.
- 배경은 불투명하게 칠한다(96%로 했을 때 뒤 창의 글자가 비쳐 보였음).

### 가방 칸
- 칸 하나 = 아이콘(32 DIP) + 이름 최대 2줄. 대상이 사라진 칸은 흐리게.
- 탐색기의 파일·폴더·바로가기, Windows 앱 목록(shell:AppsFolder)의 앱을 끌어 놓는다.
  - 빈칸이면 그 칸, 찬 칸이면 다음 빈칸부터 차례로. 모자라면 넣지 못한 개수를 알린다.
  - 파일은 원본 경로만 기억한다. 스토어 앱은 `shell:AppsFolder\<앱 식별자>`로 기억한다.
- 칸끼리 끌면 이동, 찬 칸이면 자리 바꿈.
- 칸 우클릭: 빼기, 파일 위치 열기.
- 빈 곳 우클릭: 파일로 넣기…, 작업표시줄 앱 가져오기…, Windows 앱 목록 열기, 가방 폴더 열기.
- 파일로 넣기: 파일 고르기 창(여러 개 선택, 바로가기는 따라가지 않고 그대로)으로 고른 파일을 넣는다. 빈칸을 우클릭했으면 그 칸부터, 아니면 첫 칸부터 빈칸을 채운다. 창이 떠 있는 동안 가방은 닫히지 않는다. 직접 만든 exe·배치 파일도 같은 방식으로 들어간다.
- 작업표시줄 앱 가져오기: `User Pinned\TaskBar\*.lnk` 목록(TaskPack 자신 제외)을 체크박스로 보여 주고 지금 가방과 맞춘다.
  - 같은 앱 판단: 바로가기는 "대상 경로 + 인자", 그 밖에는 경로 (대소문자 무시). 대상 경로가 없는 설치 관리자형 바로가기는 파일 이름.
  - 이미 가방에 있는 앱은 체크된 채로 보인다. 새로 체크하면 바로가기를 `bags\<id>\items\`에 복사해 넣고, 체크를 풀면 가방에서 뺀다. 가방 폴더 안의 파일은 상대 경로로 저장한다(백업을 다른 PC에서 풀어도 동작).

### 글꼴과 공통 모양
- 글꼴: `Pretendard, Malgun Gothic, Segoe UI` (App 정적 생성자에서 Window·ContextMenu·ToolTip 기본 글꼴을 바꿈). 지금은 PC에 설치된 Pretendard를 쓴다. 배포 때는 글꼴 파일과 OFL 라이선스 전문을 함께 넣는다(설치 프로그램 작업에서).
- `Styles.xaml`(App 자원): 카드, 주요/보통 버튼, 왼쪽 메뉴, 세그먼트, 색 동그라미, 스위치, 체크 목록, 얇은 스크롤바. 색은 DynamicResource라 창마다 Theme.Apply로 바꾼다.
- 설정 창은 전체 테마를, 가져오기 창은 가방 창의 지금 색을 따른다. 어두우면 Windows 제목 표시줄도 어둡게(DWMWA_USE_IMMERSIVE_DARK_MODE).

### ⚙ 설정 창 (바뀐 값은 즉시 저장)
- 구성: 왼쪽 메뉴(기본 설정·가방·백업) + 오른쪽 페이지. 가방 페이지는 가방 목록 + 선택한 가방의 카드(테마 세그먼트, 커스텀일 때 색 동그라미 12개와 "다른 색 고르기", 크기 −/+, 탭 아이콘과 이름 숨기기 스위치).
- 가방별 한 줄: 탭 아이콘 미리보기 / 이름 / 크기(가로·세로 각각 1부터 12칸까지) / 아이콘 추가·변경·삭제 / 이름 숨기기
  - 크기를 바꿔도 아이템의 (행, 열) 자리는 유지한다. 새 크기 밖으로 나가는 아이템은 빈칸으로 옮긴다. 아이템 수가 칸 수보다 많아지는 크기는 거부한다.
  - 아이콘이 없으면 "이름 숨기기"는 끈다.
- 작업표시줄 아이콘: 아이콘 미리보기 / 아이콘 바꾸기 / 기본 아이콘 / 작업표시줄에 고정하기(고정 여부 표시)
  - 고정하기: 시작 메뉴에 `TaskPack.lnk`(앱 식별자 `TaskPack.Drawer`)를 만들고 탐색기에서 선택해 보여 준다. 고정은 사용자가 한다.
  - 아이콘 교체 대상: 시작 메뉴 바로가기 + 고정된 복사본 중 앱 식별자가 같은 것. 매번 새 파일 이름으로 저장한다.
- 백업: 내보내기(zip) / 불러오기
  - 백업에 담는 것: `config.json`, `bags\`, `drawer-icon-*`
  - 불러오기 전에 현재 상태를 `restore-backup-<시각>\`로 옮겨 둔다. 풀다가 실패하면 되돌린다. zip 안의 경로가 TaskPack 폴더 밖을 가리키면 거부한다.

### 아이콘 파일
- 고를 수 있는 형식: `.ico` `.png` `.jpg` `.jpeg` `.bmp` `.exe` `.dll`
- 그림은 정사각형 256px PNG 내장 ico로 변환해 복사한다. exe·dll은 그 파일의 첫 아이콘을 가리킨다.

### 앱 아이콘
- `tools/make-icon.ps1`이 도형을 그려 `assets/TaskPack.ico`(16·20·24·32·40·48·64·256px)를 만든다. 작업표시줄 아이콘의 기본값도 이것이다.

### 저장 구조
```
%APPDATA%\TaskPack\
  config.json               { tabs: [id...], lastTab, drawerIcon, theme }
  drawer-icon-*.ico
  bags\<id>\bag.json         { name, columns, rows, hideName, tabIcon, theme?, color?, slots: [{ index, path, name? }] }
  bags\<id>\tab-icon-*.ico
  bags\<id>\items\*.lnk      가져온 작업표시줄 앱 바로가기
  deleted\                   지운 가방
  restore-backup-*\          백업 불러오기 전 상태
```
- v1 데이터: config.json이 없으면 `bags\` 아래 폴더들로 탭 목록을 만든다. bag.json은 그대로 읽는다.

## 범위 밖

- 다른 탭 위에 잠시 머물면 그 탭으로 넘어가 원하는 칸에 놓기 (지금은 첫 빈칸으로 들어감)
- 탐색기 파일을 다른 탭 위에 바로 놓기, 칸별 아이콘 바꾸기
- 창을 옮긴 위치 기억하기
- 가방이 열려 있는 동안 Windows 테마가 바뀌면 바로 따라가기 (다음에 열 때 반영)

## 검증 방법

- `dotnet build` 경고·오류 0
- 창을 띄워 화면 캡처로 탭·격자·위치 확인
- 설정·백업·가져오기 로직은 소스를 불러 쓰는 임시 테스트 프로그램으로 확인 (크기 변경, zip 왕복, 경로 밖 항목 거부)
- 끌어 놓기, 작업표시줄 고정 후 아이콘 반영은 사용자가 직접 확인

## 다음 버전 후보 (1.1.0 이후)

### 1.3 후보에 넣기로 한 것 (2026-10-01 사용자 제기)

- **설정 창에서 탭 아이콘을 바꿔도 가운데 "가방 목록"에 반영되지 않는다.** 설정 → 가방 페이지에서 아이콘(이모티콘·그림 파일)을 고르면 오른쪽 카드의 미리보기는 바뀌는데, 가운데 가방 목록의 해당 줄에는 보이지 않는다. 원인은 아직 조사하지 않았다(목록 줄을 다시 그리지 않는 것으로 의심).
- **직접 입력한 이모티콘(단색)이 탭에서 가운데 정렬에서 약간 벗어난다.** 목록에서 고른 컬러 이모티콘은 맞는데, 직접 입력한 글자 이모티콘은 글꼴 높이·여백 때문에 살짝 어긋나 보인다. 탭과 설정 미리보기 양쪽을 확인한다.

- **"실행 중" 탭**: 지금 열린 창을 가방 칸으로 보여 주고, 눌러서 그 창으로 가거나 닫는다. 실행 중인 프로그램이 많으면 작업표시줄이 붐비는 문제(사용자 제기, 2026-09-30)에 대한 보완. 작업표시줄 버튼 자체를 강제로 숨기는 방식(ITaskbarList::DeleteTab 등)은 불안정해서 제외.
- **작업표시줄 아이콘에 마우스를 올리면 가방 열기** (전역 단축키 대신, 2026-10-01 사용자 제안): 클릭 없이 아이콘 위에 잠시 머물면 가방이 뜬다.
  - 구조 변경이 크다: 마우스 위치를 계속 지켜봐야 하므로 TaskPack이 **늘 뒤에서 켜져 있어야** 한다(지금은 가방을 닫으면 프로그램이 꺼짐). Windows 시작 시 자동 실행 설정, 상주 메모리(약 50~80MB 예상, 측정 필요)가 따른다.
  - 아이콘 위치는 UI Automation으로 작업표시줄 버튼 영역을 읽어 알아낸다. 작업표시줄 위치·크기·순서가 바뀌면 다시 읽는다.
  - 지나가다 스칠 때 열리지 않게 머무는 시간(예: 0.3~0.5초)을 두고, 설정에서 끌 수 있게 한다(기본값은 정할 것).
  - Windows가 띄우는 툴팁·미리보기 창과 겹칠 수 있다. 가방을 그 위에 띄울지, 미리보기가 사라진 뒤 띄울지 화면을 보며 정한다.
  - 클릭으로 여는 지금 방식은 그대로 둔다.
- 창 위치 기억, 코드 서명("PC 보호" 경고 줄이기)

## 용어 (1.0.1)

- 작업표시줄에 고정된 아이콘은 **작업표시줄 아이콘**(설명문에서는 "작업표시줄의 가방 아이콘"), 펼쳐지는 창은 **가방**. TaskBar + Backpack이라 "서랍"은 쓰지 않는다.
- 코드의 Drawer 클래스와 식별자 TaskPack.Drawer는 이미 고정된 바로가기가 쓰므로 바꾸지 않는다.
