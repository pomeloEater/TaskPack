## TaskPack 1.1.0 — 처음 쓰는 분도 막히지 않게

설치부터 첫 사용까지 막히던 곳을 고쳤습니다.

### 설치 파일이 두 가지가 됐어요

| 파일 | 크기 | 이럴 때 |
|---|---|---|
| `TaskPack-Setup-1.1.0.exe` | 약 51MB | **처음이라면 이쪽.** .NET 8이 들어 있어 따로 설치할 것이 없습니다. ARM PC도 이쪽을 쓰세요. |
| `TaskPack-Setup-1.1.0-lite.exe` | 약 5MB | PC에 .NET 8 데스크톱 런타임(x64)이 이미 있을 때 |

- 두 파일은 같은 프로그램이라 서로 덮어 설치됩니다. 가방 데이터는 그대로 남습니다.
- lite에서 .NET 8이 없으면 설치 프로그램이 Microsoft 공식 설치 파일을 바로 받게 안내합니다. ARM64 Windows의 x64 런타임 위치도 확인합니다.
- 덮어 설치할 때 이전 설치 파일을 먼저 정리해서, 포함판과 lite를 번갈아 깔아도 실행 방식이 섞이지 않습니다.

### 처음 열었을 때

- 빈 가방 가운데에 **작업표시줄 앱 가져오기**, **파일로 넣기** 버튼이 생겼습니다.
- 작업표시줄에 고정되어 있지 않으면 가방 아래에 "작업표시줄에 고정하면 한 번에 열려요" 띠가 뜹니다. ×를 누르면 다시 보이지 않습니다.
- 첫 실행 때 설정 창이 저절로 열리던 동작은 없앴습니다.
- 빈칸·빈 곳 우클릭 → **파일로 넣기…**로 파일 고르는 창에서 여러 개를 한 번에 넣을 수 있습니다.

### 새 버전 알림

- 가방을 열 때 하루에 한 번 새 버전이 나왔는지 확인하고, 있으면 가방 아래에 알려 줍니다. **받기**는 지금 쓰는 것과 같은 판(기본/lite)의 설치 파일을 내려받습니다.
- **보내는 정보는 없습니다.** GitHub 공개 주소에서 최신 버전 번호만 읽습니다.
- 설정 → 기본 설정 → **버전**에서 현재·최신 버전을 보고, 지금 확인하거나 자동 확인을 끌 수 있습니다.
- 1.0.x에는 알림 기능이 없어서 이번 1.1.0은 직접 내려받아 설치해 주세요.

### 탭 아이콘에 이모티콘

- 설정 → 가방 → 탭 아이콘에서 컬러 이모티콘 68개 중에서 고릅니다. 목록에 없는 이모티콘은 직접 입력할 수 있고, 이때는 탭 글자색 한 가지로 보입니다.
- 이모티콘은 이름을 숨겨서 아이콘만 보이게 하는 것과도 함께 쓸 수 있고, 백업에도 담깁니다.
- 그림은 Microsoft [Fluent Emoji](https://github.com/microsoft/fluentui-emoji)(3D, MIT)입니다.

### 그 밖에

- 작업표시줄에 이미 고정해 둔 TaskPack이 "고정 안 됨"으로 보이던 문제를 고쳤고, "작업표시줄 앱 가져오기" 목록에 TaskPack 자신이 끼던 것도 고쳤습니다.
- 홈페이지와 README를 새 설치 방법에 맞게 고쳤습니다.

### 알려진 제한

- 전자 서명이 없어서 설치할 때 "Windows의 PC 보호" 창이 뜰 수 있습니다. **추가 정보 → 실행**을 누르세요.
- ARM PC는 x64 에뮬레이션으로 실행되며, 직접 확인한 기기는 아직 없습니다.

설치와 사용법은 [README](https://github.com/pomeloEater/TaskPack#readme), 홈페이지는 https://taskpack.vercel.app 에 있습니다.
