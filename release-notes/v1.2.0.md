## TaskPack 1.2.0 — 마우스를 올리기만 해도 열려요

작업표시줄의 TaskPack 아이콘에 마우스를 올려 두면 가방이 열립니다. Windows 11용이고 **기본은 꺼짐**입니다. 켜지 않으면 1.1.x와 똑같이 동작합니다.

### 마우스를 올려서 열기

- 설정 → 기본 설정 → **마우스를 올리면 열기**. 업데이트 뒤 처음 가방을 열면 가방 아래에 소개가 뜨고 거기서 바로 켤 수도 있습니다.
- 아이콘 위에 0.4초 머물면 열립니다. 스치거나 다른 아이콘 위에서는 열리지 않습니다.
- 올려서 연 가방은 **키보드 입력을 가로채지 않습니다.** 글을 쓰는 중에 마우스가 지나가도 입력은 그대로 쓰던 곳으로 갑니다. 마우스가 가방과 아이콘 밖으로 나가고 0.5초가 지나면 닫힙니다. 가방 안을 누르거나 아이콘을 누르면 일반 가방이 됩니다.
- 클릭으로 열던 방법은 그대로입니다.

### 켜면 달라지는 점 (꼭 읽어 주세요)

- 마우스를 지켜보려고 TaskPack이 **뒤에서 계속 켜져 있습니다.** 메모리는 작업 관리자 기준 약 10MB입니다.
- 시계 옆(숨겨진 아이콘 칸)에 TaskPack 아이콘이 생기고, **Windows를 시작할 때도 자동으로 켜집니다.** 시작할 때 켜는 것만 따로 끌 수 있습니다.
- 끄는 법: 설정의 스위치, 또는 시계 옆 아이콘 → 마우스오버 끄기. 끄면 자동 실행 항목도 함께 지워지고, 가방을 닫을 때 프로그램도 끝납니다.
- 마우스 위치는 "TaskPack 아이콘 위인가"를 판단하는 데만 쓰고 저장하거나 보내지 않습니다. 마우스를 가로채는 방식도 쓰지 않고, 0.05초마다 위치만 확인합니다.
- Windows 11 기본 작업표시줄에서만 동작합니다(작업표시줄에 TaskPack을 고정해 두어야 합니다). 그 밖에서는 설정에 "지원하지 않습니다"가 표시됩니다.

### 설치 프로그램

- 마우스오버를 켜 둔 상태에서 새 버전을 덮어 설치하면 자동으로 TaskPack을 끝내고 설치한 뒤 다시 켭니다.
- TaskPack을 지우면 Windows를 시작할 때 켜 두는 항목도 함께 지웁니다.
- **lite 설치 파일이 .NET 10이 있어도 "런타임이 필요합니다"라고 막던 결함을 고쳤습니다** (1.1.1의 lite 파일은 내렸습니다).

| 파일 | 크기 | 이럴 때 |
|---|---|---|
| `TaskPack-Setup-1.2.0.exe` | 약 54MB | **기본.** .NET 10이 들어 있어 따로 설치할 것이 없습니다. ARM PC도 이쪽을 쓰세요. |
| `TaskPack-Setup-1.2.0-lite.exe` | 약 5MB | PC에 .NET 10 데스크톱 런타임(x64)이 이미 있을 때 |
