## TaskPack 1.1.1 — .NET 10으로 올렸어요

화면과 기능은 1.1.0과 같습니다. TaskPack을 돌리는 Microsoft 구성 요소(.NET)를 8에서 10으로 올렸습니다. .NET 8은 2026년 11월 10일에 지원이 끝나 보안 수정이 더 나오지 않기 때문입니다.

### 설치 파일

| 파일 | 크기 | 이럴 때 |
|---|---|---|
| `TaskPack-Setup-1.1.1.exe` | 약 54MB | **기본.** .NET 10이 들어 있어 따로 설치할 것이 없습니다. ARM PC도 이쪽을 쓰세요. |
| `TaskPack-Setup-1.1.1-lite.exe` | 약 5MB | PC에 **.NET 10 데스크톱 런타임(x64)**이 이미 있을 때 |

- lite를 쓰던 분은 **.NET 10 런타임을 새로 설치해야** 합니다. 없으면 설치 프로그램이 Microsoft 공식 설치 파일(약 60MB)을 바로 받게 안내합니다. 번거로우면 기본 설치 파일을 받으세요.
- 기본 설치 파일로 덮어 설치하면 가방 데이터는 그대로 남습니다.

### 알림 (2026-10-01)

lite 설치 파일(`TaskPack-Setup-1.1.1-lite.exe`)은 .NET 10이 이미 깔려 있어도 "런타임이 필요합니다"라고 막히는 결함이 있어 **내렸습니다.** 기본 설치 파일(`TaskPack-Setup-1.1.1.exe`)은 영향이 없습니다. lite는 다음 버전에서 고쳐서 다시 올립니다.
