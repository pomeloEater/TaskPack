가방에 넣고, 한 번에 꺼내 쓰기

바탕화면을 치우고 작업표시줄을 비워도 쓰던 프로그램은 그대로 손 닿는 곳에.

자유 배치 칸

가방 크기는 1×1부터 12×12까지. 원하는 칸에 끌어다 두고, 칸끼리 끌어서 자리를 바꿉니다.

탭으로 가방 여러 개

작업용, 게임용, 공부용. 탭을 더블클릭해 이름을 바꾸고, 끌어서 순서를 바꿉니다.

끌어서 넣기

탐색기의 파일·폴더·바로가기, 시작 메뉴의 앱까지. 작업표시줄에 고정된 앱은 체크만 하면 들어갑니다.

가방마다 다른 색

시스템·라이트·다크, 또는 원하는 색으로. 글자색은 배경 밝기에 맞춰 알아서 바뀝니다.

작업표시줄 옆에 착

작업표시줄이 아래면 위로, 옆이면 옆으로 펼쳐집니다. 다시 누르거나 바깥을 누르면 닫힙니다.

zip 하나로 백업

가방과 탭 아이콘, 작업표시줄 아이콘까지 파일 하나로 내보내고 새 PC에서 그대로 되살립니다.

설치는 세 번이면 끝

  1. 1

    내려받기

    TaskPack 설치 파일을 내려받습니다. .NET 8 데스크톱 런타임이 필요하며, 없으면 설치 프로그램이 알려 줍니다.

  2. 2

    설치하기

    설치 경로와 바탕화면 아이콘을 고릅니다. 관리자 권한 없이 내 계정에 설치됩니다.

  3. 3

    작업표시줄에 고정

    시작 메뉴에서 TaskPack을 우클릭 → 작업 표시줄에 고정. Windows가 자동 고정을 막아서 이것만 직접 해 주세요.

설치 파일에 전자 서명이 없어 "Windows의 PC 보호" 창이 뜰 수 있어요. 추가 정보 → 실행을 누르면 됩니다.

자주 묻는 질문

정말 무료인가요?

네. MIT 라이선스로 공개한 오픈소스입니다. 개인·회사 모두 무료로 쓰고, 코드를 고쳐 써도 됩니다.

왜 작업표시줄 고정을 직접 해야 하나요?

Windows 10부터 프로그램이 스스로 작업표시줄에 고정하는 것을 막고 있습니다. 한 번만 고정하면 이후로는 작업표시줄의 가방 아이콘으로 바로 열립니다.

가방에 넣은 파일은 복사되나요?

아니요. 경로만 기억합니다. 원본을 옮기거나 지우면 칸이 흐리게 보여서 알 수 있습니다. 작업표시줄에서 가져온 앱만 바로가기를 가방 폴더에 복사해 둡니다.

가방 정보는 어디에 저장되나요?

내 PC의 %APPDATA%\TaskPack 폴더에만 저장되고, 어디로도 보내지 않습니다. 프로그램을 지울 때 가방 데이터를 남길지 물어봅니다.

이름이 왜 "아버지가방에들어가신다"예요?

띄어쓰기를 잘못하면 아버지가 가방에 들어가시거든요. 아이콘의 서류가방 앞 구두도 그래서 있습니다.
